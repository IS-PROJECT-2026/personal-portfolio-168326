# Daniel Morara - Personal Portfolio

## System Description
This repository contains the source code for my personal portfolio micro-system. It serves as a functional, interactive digital resume designed to showcase my academic journey in Computer Science at Strathmore University, alongside my practical software engineering and machine learning projects. 

## Live Deployment
The portfolio is deployed live via GitHub Pages. You can view the active site here:
**[View Live Portfolio](https://is-project-2026.github.io/personal-portfolio-168326/)** 

## Technologies Used
This static web project was built and deployed using:
* **HTML5:** For the structural foundation of the portfolio.
* **CSS3:** For responsive styling and visual layout.
* **JavaScript:** For dynamic interactions and user interface functionality.
* **Git & GitHub:** For version control, Agile project management, and CI/CD deployment via GitHub Pages.
